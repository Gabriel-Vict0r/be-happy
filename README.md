<h1>Be happy</h1>

<h6>Be Happy é um projeto incrível que visa promover a visibilidade de instituições de acolhimento e facilitar a organização de visitas solidárias a orfanatos.
</h6>

<h2>Tecnologias</h2>
<h3>Front-end</h3>
<ul>
<li>Javascript</li>
<li>TypeScript</li>
<li>Next.js</li>
<li>TailwindCSS</li>
<li>Map box + react-leaflet</li>
<li>Jest + Testing Library</li>
</ul>
